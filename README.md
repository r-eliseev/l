# l — учебные книги

Репозиторий книг по инженерным дисциплинам. Каждая книга — независимый
каталог `books/<slug>/`: свой контракт глав, свои источники, своя сборка в
EPUB 3. Общие инструменты — в `tools/`, они работают с любой книгой.

## Книги

| Книга | О чём | Состояние |
|---|---|---|
| [`books/ddd-praktika`](books/ddd-praktika) | Domain-Driven Design на практике: 20 глав, работающие примеры на Python | собрана, EPUB 3.0 |
| [`books/eks-course`](books/eks-course) | EKS на практике: 12 модулей по Kubernetes на AWS EKS | собран, 36 источников проверены |

## Как это устроено

```
books/<slug>/
  book.json            паспорт книги: заголовок, автор, обложка, контракт глав
  src/structure.json   оглавление: части, главы, приложения
  src/chapters/        текст глав
  src/quotes.json      банк источников с дословными цитатами
  src/evidence/        тексты страниц-источников: основа проверки дословности
  code/                пакет с примерами и тесты (не у всех книг)
  dist/                собранный EPUB

tools/                 общие инструменты: сборка, линтер глав, проверка цитат,
                       линтер машинных следов, валидация
skills/                навыки для агентов: инструкции по повторяющейся работе
docs/                  документация проекта (docs/index.md — оглавление)
tasks/                 задачи: релиз и бэклог
```

Подробности: [`docs/books.md`](docs/books.md) — как устроены книги,
[`docs/harness.md`](docs/harness.md) — как устроен харнес.

## Сборка

```bash
BOOK=ddd-praktika

python tools/lint_book.py --book $BOOK          # контракт глав
python tools/check_quotes.py --book $BOOK        # цитаты дословны
python tools/check_ai_tells.py --book $BOOK      # текст без машинных следов
python tools/build_epub.py --book $BOOK          # сборка
python tools/validate_epub.py --book $BOOK       # проверка пакета
```

Проверки харнеса (документация, задачи, навыки, опыт):

```bash
bash scripts/check.sh
```

## Правила для агентов

[`AGENTS.md`](AGENTS.md) — точка входа: порядок работы, когда что
обновлять, чего не делать. Навыки лежат в `skills/`, список показывает
`scripts/list-skills.sh`.

## Принципы

- **Примеры рабочие.** Код в главах — настоящий фрагмент пакета, который
  запускается и покрыт тестами. Линтер отвергает выдуманные блоки.
- **Цитаты дословные.** Каждая цитата сверяется с текстом источника, и
  текст источника лежит в репозитории: проверка работает на любой машине
  и в CI. Пересказ под номером источника не проходит проверку.
- **Факты проверяемы.** Версии, цены и поведение сервисов ссылаются на
  первоисточники.
- **Текст живой.** Линтер машинных следов и навык `chelovecheskiy-tekst`
  по списку «Wikipedia: Signs of AI writing».

## Лицензия

Код и тексты книг — под лицензией владельца репозитория. Навыки
`humanizer`, `grounded-citations`, `technical-book-authoring`,
`github-repo-management` взяты из набора Hermes Agent (MIT) — лицензии
лежат рядом с ними в `skills/`.
