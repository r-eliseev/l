# 0002. Примеры на Python 3.11+ без внешних зависимостей

Статус: принято
Дата: 2026-10-28

## Контекст

Иллюстрации в книге должны запускаться: читатель должен суметь взять
фрагмент и запустить. Это накладывает ограничения на язык.

- Java и C# — стандарт для литературы по DDD, но на машине владельца их
  нет, а «работающий пример» превратился бы в «пример, который нельзя
  проверить».
- TypeScript потребовал бы Node и сборки.
- Python есть, и его стандартная библиотека закрывает всё нужное:
  `dataclass`, `abc`, `Protocol`, `decimal`, `unittest`, `enum`.

## Решение

Python 3.11+, только стандартная библиотека. Тесты — `unittest`, без pytest:
чтобы читатель запустил `python -m unittest discover -s tests` без установки.

`dataclass(frozen=True)` — для объектов-значений, `slots=True` — везде.

## Альтернативы

- Java + JUnit: отвергнут — нет рантайма на машине.
- TypeScript + Vitest: отвергнут — нужна сборка и node_modules.
- Python + pytest: отвергнут — лишняя зависимость ради удобства;
  `unittest` достаточно для 50 тестов.

## Последствия

- Код в главах проверяется автоматически: линтер ищет каждый блок в пакете и
  отвергает выдуманный.
- `dataclass` с полем по умолчанию в базовом классе запрещает наследнику
  добавить обязательные поля — поэтому `occurred_at` объявлен keyword-only.
  Это видно в `books/ddd-praktika/code/ddd_examples/shared/events.py`.
