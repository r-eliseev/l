# 0004. Цитаты проверяются дословно, приложение «Источники» генерируется

Статус: принято
Дата: 2026-10-28

## Контекст

В книге 137 англоязычных цитат из 31 первоисточника, плюс приложение с
полным перечнем источников и ключевыми формулировками.

Два риска:

1. **Цитата приписана не тому источнику.** Номер разрешается, но текст
   взят из другого места — читатель откроет источник и не найдёт фразу.
2. **Приложение разошлось с текстом.** Ссылки переписаны руками, номера
   в тексте и в перечне разошлись.

Оба ловятся машинно, если источники хранятся в одном месте.

## Решение

- Ledger цитат — источник истины: id, URL, дословные цитаты. Живёт вне
  репозитория (`%LOCALAPPDATA%/hermes/cache/citations/ledger.json`).
- `book/src/quotes.json` — снимок ledger, из него берут номера и тексты.
- `book/tools/check_quotes.py` сравнивает каждую цитату главы с текстом
  источника; `--fix` перепривязывает её к правильному номеру.
- Приложение «Источники» генерируется `book/tools/build_sources_appendix.py`
  из ledger, а не пишется руками.

## Альтернативы

- Ссылки руками: отвергнут — при 137 цитатах ошибка неизбежна, а проверка
  невозможна.
- Только номера без цитат в приложении: отвергнут — приложение перестаёт
  быть проверяемым: читатель не видит, что именно взято.
- Хранить ledger в репозитории: отвергнут — он общий для всех книг и
  проектов, а не артефакт этой.

## Последствия

- Число источников в книге фиксировано снимком; новые источники в ledger не
  появятся автоматически — нужно пересобрать приложение.
- Приложение «Источники» на другой машине требует пересборки.
- Формулировка цитат в тексте должна совпадать с оригиналом посимвольно
  (с точностью до переносов строк и типографских кавычек) — это проверяет
  `check_quotes.py`, а не линтер глав.
