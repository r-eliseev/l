# Репозиторий, который работает на любой машине

## Ситуация

Два элемента проверки жили на машине автора и делали репозиторий
зависимым от неё:

- **ledger цитат** — `%LOCALAPPDATA%/hermes/cache/citations/ledger.json`:
  реестр источников с id, URL и дословными цитатами;
- **кэш извлечённых страниц** — `%LOCALAPPDATA%/hermes/cache/scratch/`:
  тексты страниц, с которыми сверяются цитаты.

Пока они лежали снаружи, проверка дословности на другой машине просто
пропускалась: `check_quotes.py` печатал «проверка пропущена» и возвращал
ноль. Проверки, которые молча не выполняются, хуже упавших: они создают
впечатление, что книга проверена.

## Что сработало

Сработало решение, обратное ожидаемому: **не «скопировать при первом
запуске», а положить в репозиторий сразу**. Источники и тексты страниц —
это данные, без которых книга не проверяема, а данные belong в git рядом с
книгой.

Что переехало в `books/<slug>/src/`:

```
quotes.json         банк источников: id → url, title, quotes[]
evidence-map.json   id → файл с текстом страницы
evidence/           тексты страниц, как их отдали при извлечении
```

Итог: 1 МБ текстов в репозитории против полного отказа проверки на любой
другой машине. Обмен — очевидный.

## Что не сработало

Не сработала попытка сделать проверку «мягкой»: сначала скрипт молча
пропускал отсутствие локального кэша, потому что так было на author's
машине. На CI это выглядело как зелёная сборка непроверенной книги.

## Доказательства

- До переноса: `python tools/check_quotes.py --book ddd-praktika` на машине
  без кэша печатал «Проверка цитат пропущена: нет локального кэша
  извлечений» и завершался с кодом 0 — то есть не проверял ничего.
- После переноса: тот же скрипт на чистой машине читает
  `books/<slug>/src/evidence/` и проверяет все цитаты. Прогон CI
  40840352057 (2026-10-28) — все четыре джоба зелёные, включая проверку
  дословности обеих книг.
- Один источник пришлось чинить: цитата потеряла открывающую скобку
  markdown-ссылки, и дословного совпадения не было. Нашёлся сверкой с
  сохранённым текстом страницы; заменена на подпись ссылки.

## Что делать в следующий раз

- Перед тем как объявить проверку «выполняется на любой машине», открыть
  репозиторий в чистом каталоге и запустить её. Локальные кэши, ~/.hermes и
  переменные окружения — источник «работает только у меня».
- Пропуск проверки должен быть заметным: ненулевой код или явная строка в
  отчёте о сборке, а не тихий успех.
- Данные, без которых артефакт нельзя проверить, belong в репозиторий.
  Файлы страниц — это данные, а не временный кэш.
