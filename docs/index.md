# Оглавление документации

| Файл | О чём | Когда читать |
|---|---|---|
| harness.md | как устроен харнес (для людей) | при знакомстве с проектом |
| product.md | цели, границы | всегда в начале |
| architecture.md | модули и потоки | при изменении структуры |
| conventions.md | стиль, тесты | перед написанием кода |
| status.md | открытые вопросы и проблемы | всегда в начале |
| tasks.md | правила работы с задачами | перед любой задачей |
| skills.md | правила работы с навыками | когда применяешь или создаёшь навык |
| experience.md | правила записи опыта | когда читаешь или пишешь запись опыта |
| audit.md | аудит: сверка документации с кодом | при аудите (раз в неделю или перед релизом) |
| subagents.md | правила для вспомогательных агентов | когда делегируешь часть работы |
| decisions/ | ADR, шаблон `_template.md` | перед спорными изменениями |
| specs/ | спецификации фич, шаблон `_template.md` | при работе над фичей |
| experience/ | опыт: что сработало, что нет, шаблон `_template.md` | перед незнакомой или рискованной работой |
| log/ | записи по сессиям, шаблон `_template.md` | при поиске контекста |

Навыки лежат не в `docs/`, а в каталоге `skills/` в корне репозитория (по одному каталогу с `SKILL.md` на навык). Список: `scripts/list-skills.sh`.
