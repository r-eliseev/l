## Известные проблемы
- `scripts/check-docs.sh` ищет битые ссылки на `.md` по всему репозиторию,
  включая `book/src/chapters/`. Ссылки вида `[1]` внутри глав не считаются
  ссылками (формат не `](...)`), поэтому ложных срабатываний нет.
- `scripts/audit.sh` опирается на GNU `date -d`: в Git Bash работает, в
  чистом `cmd` — нет.
- Приложение «Источники» (`app-d-sources.md`) генерируется из ledger, который
  лежит вне репозитория. На другой машине приложение нужно пересобрать
  (`python book/tools/build_sources_appendix.py`), иначе в нём будут старые
  цитаты.
- `book/src/quotes.json` — снимок ledger на момент сборки. Новые источники
  в ledger не появятся в книге автоматически.
