## Известные проблемы
- **GitHub Actions не запускался в приватных репозиториях этого аккаунта.**
  Джобы падали за 3 секунды, не получая раннера: ни одного шага не
  выполнялось. Проверено пробным workflow из одной строки `echo` — падало так
  же, значит дело не было в наших файлах. Публичный репозиторий владельца при
  этом работал (91 успешный прогон), приватные падали с 2026-07-17. Похоже на
  исчерпание лимита минут Actions для приватных репозиториев либо нулевой
  лимит трат. Репозиторий переведён в публичный режим и переименован в `l` —
  нужно проверить, заработали ли Actions. Если нет, лечится в настройках
  аккаунта: Settings → Billing and licensing → Budgets and alerts → Actions.
  До этого проверки запускаются локально: `bash scripts/check.sh`, `python
  tools/lint_book.py --book <slug>`, `python tools/check_quotes.py --book
  <slug>`, `python tools/check_ai_tells.py --book <slug>`, `python
  tools/build_epub.py --book <slug> && python tools/validate_epub.py --book
  <slug>`.
- `scripts/check-docs.sh` ищет битые ссылки на `.md` по всему репозиторию,
  включая `books/*/src/chapters/`. Ссылки вида `[1]` внутри глав не считаются
  ссылками (формат не `](...)`), поэтому ложных срабатываний нет.
- `scripts/audit.sh` опирается на GNU `date -d`: в Git Bash работает, в
  чистом `cmd` — нет.
- Приложение «Источники» генерируется из ledger, который лежит вне
  репозитория. На другой машине приложение нужно пересобрать
  (`python tools/build_sources_appendix.py --book <slug>`), иначе в нём будут
  старые цитаты. В CI, где ledger недоступен, приложение не пересобирается и
  сохраняется прежним.
- `books/<slug>/src/quotes.json` — снимок ledger на момент сборки. Новые
  источники в ledger не появятся в книге автоматически.
- Тексты страниц для проверки дословности лежат в кэше Hermes вне
  репозитория. На другой машине `check_quotes.py` пропускается, а не падает:
  проверка требует локальных копий страниц.
- Пороги линтера машинных следов (`tools/check_ai_tells.py`) — эвристика,
  а не корпусное измерение. Правятся в `book.json`, секция `ai_tells`.
