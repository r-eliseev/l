# Продукт: книги

## Зачем нужен проект

Репозиторий учебных книг по инженерным дисциплинам. Каждая книга —
независимый каталог `books/<slug>/` со своим контрактом глав, своими
источниками и своей сборкой в EPUB 3.

Сейчас в репозитории две книги:

- **ddd-praktika** — «Domain-Driven Design на практике»: 20 глав в 5 частях,
  ~52 000 слов, работающие примеры на Python, задачи для самопроверки и
  размышления со скрытыми ответами.
- **eks-course** — «EKS на практике»: 12 модулей о Kubernetes на AWS EKS,
  с практикой на kind и разделом «В EKS: что меняется».

## Для кого

- разработчики, которым нужен учебный материал с проверяемыми примерами;
- тимлиды и архитекторы, выбирающие, где подход уместен, а где оверинжиниринг;
- преподаватели и менторы, которым нужен готовый материал с проверками.

## Границы: что делаем

- Книги в `books/<slug>/`: исходники глав, пакет с примерами, банк источников,
  собранный EPUB.
- Общие инструменты в `tools/`: сборка EPUB, линтер глав, проверка дословности
  цитат, линтер машинных следов, валидация пакета.
- Фактические утверждения книг проверяются по первоисточникам, цитаты — дословно.
- Каждая книга собирается в EPUB 3 и проверяется в CI.

## Границы: что не делаем

- Не пересказываем чужие книги: даём определения из первоисточника и
  собственные примеры.
- Не пишем ответы на вопросы «Проверь себя» — их формулирует читатель.
- Не добавляем главы, которые нельзя проверить линтером (выдуманный код,
  ненадёжные цитаты).
- Не смешиваем книги: примеры и терминология у каждой свои.

## Термины

| Термин | Значение |
|---|---|
| Книга | Каталог `books/<slug>/` с файлом `book.json` |
| Паспорт | `book.json`: заголовок, автор, обложка, контракт главы |
| Оглавление | `books/<slug>/src/structure.json`: части, главы, приложения |
| Контракт | Набор правил главы из `book.json`: секции, числа вопросов, код |
| Глава | Один Markdown-файл в `books/<slug>/src/chapters/` |
| Скрытый ответ | Блок `<details markdown="1">` с ответом в главе |
| Источник | Запись в `books/<slug>/src/quotes.json`; в тексте обозначается `[n]` |
| Пакет | `books/<slug>/code/<package>/` — примеры, покрытые тестами |
| Линтер | `tools/lint_book.py` — проверка контракта глав |
| Ledger | `%LOCALAPPDATA%/hermes/cache/citations/ledger.json` — источники и цитаты |
