# Продукт: ddd-praktika

## Зачем нужен проект

Учебная книга «Domain-Driven Design на практике» на русском языке: 20 глав в
5 частях, ~52 000 слов, с примерами кода, задачами для самопроверки и
размышлениями со скрытыми ответами. Собирается в EPUB 3.

Книга учит DDD не по диаграммам, а на работающем коде: все иллюстрации —
настоящие фрагменты пакета `ddd_examples`, который запускается и покрыт
тестами. Цитаты из первоисточников проверяются дословно, номера источников
соответствуют приложению «Источники».

## Для кого

- разработчики, знакомые с ООП и веб-фреймворками, но не с DDD;
- тимлиды и архитекторы, выбирающие, где DDD уместен, а где оверинжиниринг;
- преподаватели и менторы, которым нужен готовый учебный материал с
  проверяемыми примерами.

## Границы: что делаем

- Исходники глав в `book/src/chapters/` (Markdown, 9 обязательных секций).
- Пакет с примерами `book/code/ddd_examples/` + тесты `book/code/tests/`.
- Сборка EPUB 3 (`book/tools/build_epub.py`) и проверки (`lint_book.py`,
  `check_quotes.py`, `validate_epub.py`).
- Приложение «Источники» генерируется из ledger цитат, а не пишется руками.

## Границы: что не делаем

- Не пересказываем «синюю книгу» Эванса: даём определения из первоисточника
  и собственные примеры, но не пересказ глав.
- Не пишем ответы на вопросы «Проверь себя» — их формулирует читатель.
- Не делаем книгу про микросервисы, CQRS или Event Sourcing как таковые:
  это части DDD, а не самоцель.
- Не добавляем глав, которые нельзя проверить линтером (выдуманный код,
  ненадёжные цитаты).

## Термины

| Термин | Значение |
|---|---|
| Глава | Один Markdown-файл в `book/src/chapters/` с девятью секциями |
| Секция | Обязательный заголовок внутри главы (см. `book/src/STYLE.md`) |
| Скрытый ответ | Блок `<details markdown="1">` с ответом в главе |
| Источник | Запись в ledger цитат; в книге обозначается `[n]` |
| Пакет | `book/code/ddd_examples/` — учебный домен и инфраструктура |
| Линтер | `book/tools/lint_book.py` — проверка контракта глав |
| Ledger | `%LOCALAPPDATA%/hermes/cache/citations/ledger.json` — источники и цитаты |
