# Проверка фактов в главе

Книга обещает читателю, что примеры работают и утверждения верны. Обещание
выполняется двумя разными проверками: код проверяется запуском, утверждения —
сверкой с первоисточником. Эта инструкция про вторую.

## Когда применять

- В главу пишут утверждение, которое можно оспорить: версия, цена, лимит,
  срок поддержки, поведение сервиса, имя команды или параметра.
- Готовится новая книга или новый модуль: план факт-чека до написания.
- Ревьюер сомневается в цифре или дате.

Не применять к оценочным суждениям («удобнее», «проще») и к определениям,
которые даны со ссылкой на источник.

## Порядок

### 1. Выделить проверяемые утверждения

Пройти по тексту и выписать всё, что можно опровергнуть:

| Тип | Пример |
|---|---|
| Версия | «Kubernetes в EKS 1.34–1.37», «kind v0.33.0» |
| Цена | «~$0.10 за час» |
| Поведение сервиса | «VPC CNI даёт поду настоящий IP из VPC» |
| Команда и результат | «`kubectl get componentstatuses` ничего не покажет» |
| Срок | «стандартная поддержка 14 месяцев» |
| Наличие и статус | «ALB Ingress Controller переименован в AWS Load Balancer Controller» |

Сомнительное — в отдельный список. Утверждение, которое нельзя проверить
первоисточником, либо удаляется, либо получает пометку «проверьте».

### 2. Найти первоисточник

Приоритет: официальная документация вендора > исходный код > release notes >
обзорные статьи. Пересказ в блоге первоисточником не является.

```bash
# страницу надо сохранить целиком: без сохранённого текста цитату не проверить
python - <<'PY'
import pathlib, urllib.request
url = "https://docs.aws.amazon.com/eks/latest/userguide/what-is-eks.html"
out = pathlib.Path("scratch/eks_what_is.txt")
out.parent.mkdir(exist_ok=True)
out.write_bytes(urllib.request.urlopen(url).read().decode("utf-8", "replace"))
print(out, out.stat().st_size)
PY
```

Для книг, где страницы отдаются JavaScript, текст снимают через извлечение
(`web_extract`) и сохраняют в файл.

### 3. Привязать утверждение к источнику

Каждое утверждение получает номер источника — id из `quotes.json` книги.
Текст источника копируется **дословно**, из сохранённой страницы, а не по
памяти: пересказ не совпадёт при проверке.

```json
"7": {
  "url": "https://docs.aws.amazon.com/eks/latest/userguide/...",
  "title": "Amazon EKS — что это",
  "quotes": [
    "Amazon EKS is a managed Kubernetes service that makes it easier to run Kubernetes on AWS."
  ]
}
```

Цитата обязана дословно встречаться в сохранённом тексте страницы. Это
проверяется автоматически: `tools/check_quotes.py --book <slug>`.

### 4. Поставить ссылку в текст

Ссылка `[n]` ставится сразу после предложения, которое источник
подтверждает, — не в конце абзаца и не списком в конце главы.

```
VPC CNI выдаёт поду настоящий IP из VPC, а не адрес из отдельного диапазона.[4]
```

В конце главы — секция `## Источники главы` со списком `[n] Название — URL`.
Номера в списке совпадают с номерами, реально встречающимися в тексте.

### 5. Проверить

```bash
python tools/lint_book.py --book <slug>       # номера разрешаются, ссылки не висят
python tools/check_quotes.py --book <slug>     # цитаты дословны и привязаны верно
```

Первая проверка убеждается, что id существует. Вторая — что цитата
действительно лежит в тексте источника. Только вторая отвечает на вопрос
«откуда это взялось».

## Как проверить результат

- `check_quotes.py` — «Все цитаты дословны и привязаны верно».
- В `quotes.json` для каждого id есть URL и хотя бы одна дословная цитата.
- В каждой главе с фактами есть `## Источники главы`, и номера в нём совпадают
  с номерами в тексте.
- Утверждения, которые не удалось подтвердить, отсутствуют в тексте, а не
  помечены сноской.

## Частые ошибки

- **Цитата придумана по памяти.** Не проходит проверку дословности: текст
  отличается хоть на слово. Копировать из сохранённой страницы.
- **Один источник на десять утверждений.** Номер не привязывает конкретный
  факт к конкретному месту в источнике. Один источник — одно утверждение.
- **Источник в блоге.** Первоисточник важнее удобства цитирования.
- **Проверка после публикации.** Тогда факт уже напечатан. Проверять до.
- **«Это же очевидно».** Очевидное устаревает быстрее всего: цены, лимиты и
  названия ресурсов меняются каждый квартал.
- **Мёртвый URL.** Ссылка должна открываться; проверять рукой перед
  коммитом.
