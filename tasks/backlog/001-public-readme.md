# README в корне репозитория

## Описание

В корне репозитория нет README: есть только `book/README.md`, который
описывает сборку, но не отвечает на вопрос «что это за репозиторий и где
скачать книгу».

Для приватного репозитория README всё равно полезен: он виден в веб-интерфейсе
GitHub при первом заходе по ссылке.

## Критерии готовности

- `README.md` в корне: что это, как скачать EPUB, как запустить примеры, где
  документация харнеса.
- Ссылка на собранную книгу (`book/dist/ddd-praktika.epub`).
- Команда запуска тестов и сборки — как в `AGENTS.md`.
- Раздел «Структура репозитория» со ссылками на `book/`, `docs/`, `tasks/`.
- `scripts/check.sh` проходит после правки.
